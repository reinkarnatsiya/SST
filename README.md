# Задание
Составить техническое задание по выбранной теме, согласно образцу.

## Корректировки

1. В разделе **1.Термины и определения** остается только содержимое пункта "1.1.Общие термины". Остальные пункты не прописываются.
2. По всему тексту технического задания нумерация может быть 1,2,3 либо 1.1, 2.1, 3.2. **Не глубже.** Все подпункты формата 2.1.1. или 2.2.1.1. заменяются на маркированные списки с "-" либо же описываются единым текстом, как абзац, а не списком.
3. Раздел **2.4.Использование Технического Задания** не прописывается.
4. Если в пункте (см. ниже) нечего прописывать, т.е. требования не предъявляются, то и включать его в ТЗ **не нужно вообще**.

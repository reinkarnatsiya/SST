# Материалы для выполнения практических работ по курсу МДК.01.02 Поддержка и тестирование программных модулей

> ***Примечание***:  
> Данный файл использует форматирование на языке [Markdown](https://commonmark.org/help/).

В ветках данного репозитория размещены практические задания по курсу МДК.01.02 Поддержка и тестирование программных модулей для специальности 09.02.07 Информационные системы и программирование. Каждая практическая работа размещена в отдельной ветке и содержит набор намеренных ошибок, которые необходимо найти с помощью тестирования.

---

## Ветки репозитория

| Ветка | Назначение |
|-------|------------|
| `w-3-...` | Практическая работа для 3 курса |
| `w-4-...` | Практическая работа для выпускников |
| `df` | Задание для дифференцированного зачёта |

> Практические работы размещаются в отдельных ветках по мере их подготовки.

---

## Требования к выполнению работ

- Допускается выполнение работ как **самостоятельно**, так и в **малых группах (до 4 человек)**
- Результатом работы является **рабочее пространство в FIRETMS** (система управления тестированием). Для проверки необходимо добавить преподавателя в проект и предоставить доступ к доске, либо продемонстрировать доску на компьютере в аудитории.
- По каждой работе предусмотрены **устные вопросы** по теме – ответы на них также влияют на оценку.
- При выполнении работы в группе оценка выставляется **индивидуально на основе личного вклада в рабочий процесс**.
